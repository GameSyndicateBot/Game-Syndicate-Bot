# GS CORE V19.7.9 — QUICK EVENT MAFIA UX

- В Mafia Lite добавлен публичный список всех участников со статусом жив/выбыл.
- Список показывается при старте, каждой ночи и каждом дневном голосовании.
- Мафия получает в личных сообщениях интерактивное меню выбора жертвы.
- Случайное убийство при отсутствии выбора полностью удалено: если мафия не выбрала цель, ночью никто не погибает.
- Дневное голосование переведено на интерактивный список живых игроков.
- Игрок может изменить ночную цель или дневной голос до завершения соответствующей фазы.
