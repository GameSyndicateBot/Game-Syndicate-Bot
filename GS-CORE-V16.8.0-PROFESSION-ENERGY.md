# GS CORE V16.8.0 — Энергия профессий и кооперация

- Игровые профессии: Травник, Горняк, Лесник, Рыбак, Охотник.
- Повар удалён из списка профессий игроков: Повар, Алхимик и Кузнец остаются NPC-сервисами Гильдии.
- Один герой может выбрать только одну профессию.
- Максимум профессиональной энергии: 100.
- Одна работа стоит 20 энергии.
- Энергия восстанавливается автоматически по 5 единиц в час, даже когда бот перезапущен.
- Удалён старый четырёхчасовой кулдаун: ограничением теперь служит энергия.
- Добавлена команда `/profession server`, показывающая, каких профессий не хватает серверу.
- Каждая профессия получила собственный набор обычных и редких ресурсов.
- Все награды профессий попадают в существующий инвентарь/хранилище героя через hero_inventory.

После установки требуется повторная регистрация slash-команд: `npm run deploy:prod`.
