# GS CORE V19.3.3 — Blitz Empty Lobby Fix

- После завершения матча прежние участники больше не переносятся в новое лобби автоматически.
- Новое лобби создаётся пустым: `Записалось: 0`.
- Новый матч начинается только после новых нажатий кнопки «Играть».
- Игроки, которые осознанно нажали «Играть» во время активного матча, могут остаться в очереди следующего матча.
- Сохранены 10 секунд на ответ, рейтинг +1 за победу, ротация категорий и защита от повторов.
