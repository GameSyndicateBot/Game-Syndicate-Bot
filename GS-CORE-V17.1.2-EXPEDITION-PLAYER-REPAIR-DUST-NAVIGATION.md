# Game Syndicate V17.1.2

## Полное восстановление игрока 468683569359880192

При первом запуске бот:
- завершает его зависшие активные экспедиции без награды и штрафа;
- удаляет кулдаун экспедиции;
- ставит герою статус `ready`;
- очищает `recovery_until`;
- полностью восстанавливает HP.

Предыдущий патч удалял только запись кулдауна, поэтому герой мог оставаться со статусом `expedition` и получать сообщение «Герой сейчас недоступен».

## Навигация GS Dust

Во всех экранах распыления добавлена кнопка возврата:
- основной список повторок;
- информация о Dust;
- подтверждение одной карточки;
- подтверждение массового распыления;
- экран результата.

Кнопка возвращает непосредственно в `/gs` → GS Hub.
