# GS CORE V18.3.8 — Unified Resource System

## Исправлено
- Хранилище, Кузнец, Алхимик, Повар, улучшения и Доска заказов используют одну таблицу `hero_materials`.
- Старые материалы из `hero_inventory` автоматически переносятся в единое хранилище при запуске.
- Железная руда и другие ресурсы сразу видны всем ремесленным системам.
- Новые ресурсы профессий и экспедиций больше не создают второй, скрытый баланс.
- В окне улучшения показывается точный список недостающих ресурсов.

## Миграция
Миграция идемпотентна: старые строки материалов переносятся один раз и удаляются из `hero_inventory`, поэтому повторный запуск не удваивает ресурсы.
