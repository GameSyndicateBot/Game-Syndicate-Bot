1. Остановите бота.
2. Сделайте резервную копию database.sqlite.
3. Скопируйте содержимое этого патча в корень проекта с заменой файлов.
4. Выполните npm install при необходимости.
5. Зарегистрируйте slash-команды вашим штатным скриптом и перезапустите бота.

Одноразовые восстановления защищены ключом миграции и не дублируются при повторных перезапусках.
