GS CORE V19.1.1 — SMALL PATCH

Как установить:
1. Распакуйте архив.
2. Скопируйте содержимое папки GS-V19.1.1-SMALL-PATCH в корень текущего проекта бота.
3. Подтвердите замену существующих файлов.
4. Не удаляйте остальные папки проекта.
5. Выполните npm install (если хост требует обновить зависимости).
6. Зарегистрируйте slash-команды обычным способом проекта.
7. Перезапустите бота.

Патч содержит только изменённые и новые файлы, поэтому он намного меньше полного архива.
Перед установкой сохраните резервную копию базы данных и текущего проекта.
