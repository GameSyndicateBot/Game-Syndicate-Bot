# GS CORE V19.6.0 — WEEKLY LOTTERY

- `/lottery` opens a private weekly lottery hub.
- One ticket per player per round, price: 100 GS Dust.
- Base prize pool: 3000 GS Dust; every ticket adds 100.
- Automatic draw every Saturday at 21:00 Moscow time.
- Winner receives the full pool; a new round opens automatically.
- Dynamic card displays up to 30 current server display names.
- Buttons: buy ticket, refresh, winner history.
- Lottery purchases and winnings are written to the economy log.
