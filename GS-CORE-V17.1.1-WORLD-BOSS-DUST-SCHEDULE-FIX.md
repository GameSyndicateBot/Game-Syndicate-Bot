# Game Syndicate V17.1.1 — World Boss Dust & Schedule Fix

## Расписание
World Boss снова появляется по утверждённому расписанию:
- 13:00 МСК
- 20:00 МСК

## Общая награда GS Dust
Исправлена возможная причина, по которой обычные участники не получали свою долю:

`addCardDust()` выполнял только `UPDATE players`.
Если у участника ещё не существовало строки в таблице `players`, обновлялось 0 строк и награда терялась.

Теперь после победы бот:
- гарантированно создаёт недостающую запись игрока;
- делит весь общий фонд между всеми участниками;
- начисляет Dust в одной транзакции;
- проверяет баланс каждого игрока после начисления;
- сохраняет подробный список начислений в итогах боя;
- показывает в финальной карточке, кто и сколько получил.

Если хотя бы одно начисление не прошло проверку, транзакция откатывается и в лог выводится точная ошибка вместо частично выданных наград.
