# GS CORE V18.3.10 — STRICT COLLECTION AUDIT

## Исправлено

- Common/Rare/Epic/Legendary/Mythic теперь требуют все 13 базовых карточек именно в соответствующем варианте редкости.
- Exclusive и Holographic требуют все карточки своих отдельных коллекций.
- Удалены ручные исключения, которые могли выдавать достижения без фактически полного набора.
- При запуске бот проверяет уже выданные карточные достижения.
- Ошибочные достижения автоматически снимаются.
- Одновременно откатываются награды достижения: XP, AP и доступный GS Dust.
- Запись о Dust удаляется, поэтому после настоящего завершения коллекции награда снова будет выдана корректно.
- Каждое снятие записывается в таблицу `collection_achievement_revocations`.

## Лог запуска

`[Collection Achievements Audit] checked=N, revoked=N, users=N, dustRemoved=N`
