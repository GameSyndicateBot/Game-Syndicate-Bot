# GS CORE V19.7.6 — GIFT USER SELECT & DPS DEX BUFF

- Fixed the root cause of the gift recipient timeout: Discord UserSelectMenu interactions are now routed through the global component handler.
- Gift menus remain ephemeral and visible only to the player who opened them.
- DPS World Boss Dexterity scaling increased from 1% per 2 equipped Dexterity to 1% per 1 equipped Dexterity.
- Dedicated equipment Dexterity bonus is capped at +40% outgoing damage.
- Only Dexterity from equipped items of the active class is counted.
