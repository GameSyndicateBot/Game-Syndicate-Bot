# Version 18.2.0 — усиление миньонов

- Урон всех атакующих миньонов мирового босса существенно повышен.
- При действии «Призыв» босс вызывает случайно от 1 до 3 миньонов.
- Одновременно на поле по-прежнему может находиться не более 3 живых миньонов босса.
- При недостатке свободных мест призывается только доступное количество.
- Тип каждого нового миньона выбирается случайно из набора конкретного босса; повторы разрешены.
