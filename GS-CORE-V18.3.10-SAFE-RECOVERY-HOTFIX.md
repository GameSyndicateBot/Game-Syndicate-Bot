# GS CORE V18.3.10 — Safe Recovery Hotfix

- Удалена персональная автоматическая миграция для конкретного Discord ID.
- Ни один игрок больше не освобождается по заранее прописанному ID.
- `/admin rpg unstuck` отказывается менять состояние, если существует активная экспедиция.
- Команда очищает состояние только когда герой помечен `expedition`, но активной экспедиции нет, либо когда истёк статус восстановления после ранения.
- Автовосстановление при запуске сохраняет самую новую активную экспедицию и исправляет только противоречивые состояния.
