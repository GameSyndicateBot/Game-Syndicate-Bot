# GS CORE V18.3.8 — Final Profile & Crafting Categories

## Профиль героя
- Карточка Гильдии показывает класс из самой последней отправленной экспедиции.
- Активная экспедиция также учитывается сразу после старта.
- Если экспедиций не было, используется стартовый класс героя.

## Crafting System V2
- Проверка открытия рецепта идёт по реальному `heroes.level`.
- Герой 2 уровня видит рецепты 1 уровня открытыми; блокировка остаётся только при нехватке Dust/материалов.
- Добавлены категории кузницы: Все, Оружие, Броня, Украшения, Расходники, Доступные, Заблокированные.
- Выбранная категория сохраняется при открытии рецепта и возврате назад.
- Карточка рецепта показывает уровень, Dust, материалы, источники добычи и точную причину недоступности.
