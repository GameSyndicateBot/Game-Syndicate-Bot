# Game Syndicate V17.0 — Guild Registry & Profession Progression

## Реализовано

### Профессии
- 5 профессий: Травник, Горняк, Лесник, Рыбак, Охотник.
- Максимальный уровень профессии увеличен до 50.
- Энергия растёт каждые 5 уровней.
- Стоимость работы снижается на 20 и 40 уровнях.
- Шанс редкой добычи и объём обычной добычи растут с уровнем.
- На 50 уровне открывается постоянная специализация.
- Учитываются собранные ресурсы, выполненные заказы и заработанный Dust.

### Реестр Гильдии
- Список героев.
- Статистика классов.
- Статистика профессий.
- Общая статистика RPG-экономики.
- Новый раздел «Зал мастеров».

### Зал мастеров
- Топ-5 для каждой профессии.
- Сортировка: уровень профессии → XP → число работ.
- Первое место отмечается короной.
- В рейтинге отображается специализация мастера.

### Хранилище
- В Guild Hub добавлена отдельная кнопка ресурсов.
- Показываются только материалы.
- Добыча профессий автоматически хранится среди ресурсов героя.

### Доска заказов
- /orders create — создать заказ с резервированием Dust.
- /orders list — открыть доску.
- /orders fulfill — частично или полностью выполнить заказ.
- /orders mine — свои заказы.
- /orders cancel — отменить заказ и вернуть неиспользованный резерв.
- При выполнении материалы и Dust передаются автоматически.
- За выполнение начисляется опыт профессии.

## Безопасность обновления
- Новые таблицы создаются автоматически.
- Новые столбцы hero_professions добавляются через миграции.
- Существующий прогресс героев и профессий сохраняется.
