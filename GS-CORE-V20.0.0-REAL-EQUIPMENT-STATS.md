# GS CORE V20.0.0 — Real Equipment Stats

- Added visible Strength, Dexterity, Intelligence, Wisdom, Vitality and Luck.
- Equipped class loadout, artifacts, pets and mount are included in current totals.
- Item bonuses now affect World Boss damage/healing/HP/resistance, expeditions and dungeon group power.
- `/hero stats` shows current totals, equipment contribution and derived effects.
- Legacy Defense remains supported for old items.
