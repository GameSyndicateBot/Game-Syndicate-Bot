# GS CORE V18.5.3 — GUILDMATES EPHEMERAL & BOMB FIX

## Гильдия героев
- Кнопка **Гильдейцы** больше не заменяет основное меню Гильдии.
- Список Кузнеца, Алхимика, Лекаря и Повара открывается временно и виден только нажавшему игроку.
- Убрана лишняя кнопка возврата из временного меню.

## Quick Event: Бомба
- Убрана жёсткая проверка ответов по короткому встроенному словарю.
- Корректные редкие названия игр и другие тематические ответы теперь принимаются.
- Каждый новый уникальный безопасный ответ получает реакцию ✅ и фиксирует последнего игрока.
- Повторы по-прежнему не принимаются. Ссылки, упоминания и слишком длинные сообщения отбрасываются.
