# GS CORE V19.6.8 — Blacksmith Clean Menus

- Removed unrelated navigation buttons `Алхимик`, `Питомцы`, and `Артефакты` from the Blacksmith main screen.
- Removed the same unrelated buttons from item crafting details and item upgrade details.
- Crafting and upgrade screens now keep only their relevant `Назад`, `Создать`, or `Улучшить` controls.
- Added one compact `К гильдейцам` button to the main Blacksmith screen.
- Error states return the player directly to the Blacksmith instead of showing unrelated NPC/system buttons.
