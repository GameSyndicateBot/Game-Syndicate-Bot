# GS CORE V19.8.3 — WORLD BOSS 4-TURN RESPONSE

## Изменения

- Босс больше не атакует автоматически только в конце полного круга игроков.
- Ответная атака босса выполняется после каждых 4 завершённых ходов игроков.
- Ход босса не входит в очередь и не может пропустить следующего игрока.
- Смерть игрока во время ответа босса безопасно пересобирает очередь по Discord user ID.
- Каждая 4-я собственная атака босса получает +30% урона.
- Каждая 3-я собственная атака босса (после 12 ходов игроков) принудительно использует особую атаку.
- Периодичность механик, проклятий, призывов, АоЕ и ярости теперь считается по собственным действиям босса, а не по полным раундам игроков.
- Горение Пироманта и действия призывов игроков по-прежнему срабатывают в конце полного раунда.
