# GS CORE V19.2.3 — GS BLITZ STABILITY FIX

Исправлено зависание GS Blitz между раундами и после финала.

- Telegram API-запросы повторяются до трёх раз при временных ошибках.
- Ошибка отправки вопроса или результата больше не обрывает цепочку матча.
- Добавлено автоматическое восстановление игры через 3 секунды.
- Защита от двойного завершения одного раунда.
- Защита от устаревших таймеров после `/blitzreset` и создания нового лобби.
- После определения победителя новое лобби создаётся даже при ошибке отправки финального сообщения.
- Когда все живые игроки ответили, раунд завершается раньше, без ожидания полного таймера.
- Старые кнопки ответа теперь получают корректное уведомление вместо передачи в другие обработчики.
- Сохранено исправление проверки администратора для `/setblitz` и `/blitzreset`.

Базы данных и `.env` в обновление не включаются.
