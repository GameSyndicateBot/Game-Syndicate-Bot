# GS CORE V18.4.1 — DUNGEON HUB UI

- Добавлена отдельная широкая иллюстрация хаба групповых данжей.
- Основное сообщение оформлено в едином стиле других RPG-хабов Game Syndicate.
- Чётко отображаются открытое/закрытое окно, крайнее время запуска и длительность рейда.
- Отдельными блоками показаны активные группы, участники, ограничения и подсказка анализа состава.
- Изображение прикрепляется один раз и повторно используется при обновлении счётчиков, чтобы не создавать дубликаты вложений.
