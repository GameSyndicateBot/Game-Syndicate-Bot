# Game Syndicate V17.2.0 — Quick Events V2

## Равный шанс режимов
- Все активные Quick Events получили одинаковый базовый шанс появления.
- Интерактивные события больше не занижены по весам.
- `music_guess` временно исключён из ротации, пока нет полноценной медиатеки.

## Антидубликат режимов
- Бот исключает последние 7 режимов из следующего выбора.
- Если список когда-либо станет слишком маленьким, как минимум последний режим всё равно не повторяется.
- Выбор среди доступных режимов полностью равномерный.

## Антидубликат заданий
- Для статических заданий действует окно без повторов 14 дней.
- Проверяются текст задания, отображаемое значение, ответы, варианты, тема и скрытые слова.
- До 40 попыток выбирается новое задание.
- Если весь небольшой набор уже использован, событие всё равно запускается и не ломает расписание.

## Музыкальный режим
- Временно отключён из автоматической ротации.
- Код режима сохранён для будущего наполнения медиатеки.
