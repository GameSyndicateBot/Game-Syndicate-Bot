# V20.3.2 — Expedition return fix

Исправлен сбой при нажатии «Забрать результат» после возвращения из экспедиции.

Причина: `expeditionService.js` использовал `ITEMS` при фильтрации награды экспедиции, но `ITEMS` не был импортирован из `itemData.js`. При успешном исходе с попыткой выдать предмет возникал `ReferenceError: ITEMS is not defined`, из-за чего экспедиция оставалась активной и пользователь видел «Произошла ошибка».

Исправление: добавлен импорт `ITEMS`. Уже зависшие завершённые экспедиции не требуют ручной правки БД — после установки патча игрок может снова нажать «Забрать результат», и расчёт завершится штатно.
