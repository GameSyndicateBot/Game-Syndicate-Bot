# Game Syndicate — Expedition System V2

## Что исправлено

- Учитываются все надетые предметы активного классового комплекта.
- Классовый комплект заменяет только совпадающие слоты, а не отключает общий комплект целиком.
- Учитываются оба надетых артефакта.
- Учитываются активные питомцы по отдельности.
- Учитывается надетый маунт по отдельности.
- Улучшения предметов, артефактов, питомцев и маунта применяются к их характеристикам.
- Все написанные числовые характеристики активного комплекта участвуют в расчёте героя.
- Профильная характеристика локации влияет на успех сильнее остальных.
- `expedition_success` добавляется напрямую к шансу.
- `luck` и `rare_find` влияют на редкую добычу.
- `injury_resistance` снижает риск/тяжесть ранения.
- Финальный шанс успеха жёстко ограничен 80%.
- При запуске экспедиции сохраняется снимок комплекта и рассчитанных бонусов.
- Смена или передача вещей после старта не меняет уже запущенную экспедицию.
- Меню экспедиции показывает вклад экипировки, артефактов, питомцев и маунта.
- В консоль пишется раздельная диагностика источников бонусов.

## Установка

Скопируй папки `systems` и `commands` в корень проекта с заменой файлов.

Заменяются 4 файла:

- `systems/hero/itemService.js`
- `systems/hero/companionService.js`
- `systems/hero/expeditionService.js`
- `commands/expedition.js`

После замены перезапусти бота.

## Проверка

1. Сними всё и открой меню экспедиции.
2. Надень один предмет — цифры должны измениться.
3. Надень маунта — строка маунта должна стать ненулевой.
4. Активируй питомца — строка питомцев должна измениться.
5. Надень артефакт в каждый слот — строка артефактов должна измениться.
6. Улучши один объект — его вклад должен увеличиться.
7. Собери сильный комплект — шанс не должен превысить 80%.
8. Запусти экспедицию, затем сними вещи — результат должен использовать стартовый комплект.
