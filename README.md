# GS CORE V20.2.1 — EXPEDITION FULL LOADOUT FIX

Исправлен расчёт экипировки и спутников в экспедициях.

## Что исправлено

- Классовый комплект больше не отключает все остальные надетые предметы.
  Предметы класса переопределяют только совпадающие слоты, остальные слоты берутся из общего комплекта героя.
- В шанс экспедиции теперь попадает весь активный комплект:
  - обычная экипировка;
  - классовая экипировка;
  - оба артефакта;
  - активные питомцы;
  - активный маунт.
- Улучшения артефактов теперь учитываются во всех расчётах характеристик.
- Улучшения маунтов и питомцев, которые имеют зеркальную запись в инвентаре, усиливают их активные бонусы.
- Исправлено использование выбранного класса экспедиции при расчёте эффективного комплекта.
- Неосновные характеристики предметов теперь тоже дают небольшой вклад в шанс экспедиции, поэтому оружие, шлемы, кольца и другие слоты не игнорируются полностью.
- Максимальный итоговый шанс экспедиции возвращён к лимиту 90%.
- Добавлен учёт бонуса `heal` в общем наборе характеристик экипировки.

## Изменённые файлы

- `systems/hero/itemService.js`
- `systems/hero/companionService.js`
- `systems/hero/expeditionService.js`

## Проверка

После запуска сравнить ожидаемый шанс одной и той же экспедиции:

1. С полностью надетым комплектом.
2. После снятия одного предмета.
3. После снятия маунта.
4. После снятия питомца.
5. После снятия артефакта.

Каждый источник с ненулевыми характеристиками должен менять расчёт. Изменение может быть небольшим из-за ограничителей баланса и округления интерфейса.
