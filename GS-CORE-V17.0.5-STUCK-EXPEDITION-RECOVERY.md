# Game Syndicate V17.0.5 — Stuck Expedition Recovery

При первом запуске этой версии бот один раз:

- завершает все записи экспедиций со статусом `active`;
- помечает их как отменённые по причине технического восстановления;
- возвращает всех связанных героев в состояние `ready`;
- полностью восстанавливает HP;
- очищает `recovery_until`;
- дополнительно исправляет героев со статусом `expedition`, даже если активная запись экспедиции отсутствует;
- не выдаёт награды и не назначает штрафной кулдаун.

Миграция защищена ключом и повторно при следующих перезапусках не выполняется.
