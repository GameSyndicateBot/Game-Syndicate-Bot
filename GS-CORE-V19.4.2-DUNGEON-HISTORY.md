# GS CORE V19.4.2 — Dungeon History

- В хаб групповых подземелий добавлена кнопка `📜 История`.
- История открывается лично нажавшему пользователю и перелистывается кнопками.
- Для каждого завершённого рейда сохраняются результат, сложность, шанс группы, участники, Dust, опыт класса и выпавшие предметы.
- Для новых предметов в истории сохраняются название, редкость, слот, описание, lore и полный JSON характеристик.
- Старые записи дополняются актуальными данными из каталога предметов, когда item_key сохранился.
- Подробный отчёт о завершении данжа больше не отправляется в общий канал подземелий.
- После завершения обновляется только хаб, поэтому канал не захламляется.
