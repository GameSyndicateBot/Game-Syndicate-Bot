# Game Syndicate V20.3.1 — Market Sell UI Fix

Исправлен сбой `DiscordAPIError[50035]: data.components[BASE_TYPE_MAX_LENGTH]: Must be 5 or fewer in length` в `Рынок -> Продать`.

Причина: у игроков, у которых одновременно были материалы, экипировка/артефакты, расходники и питомцы/маунты, экран продажи создавал 6 ActionRow: 4 выпадающих меню + отдельная строка действий + отдельная строка «Назад». Discord разрешает максимум 5 строк компонентов.

Исправление: кнопки «Продать кузнецу», «Создать заказ» и «Назад на рынок» объединены в одну строку. Максимум теперь 5 ActionRow, поэтому интерфейс одинаково открывается и у больших инвентарей.
