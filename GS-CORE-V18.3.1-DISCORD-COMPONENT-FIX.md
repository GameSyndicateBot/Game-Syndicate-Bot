# GS Core v18.3.1 — Discord component fix

- Исправлено дублирование `custom_id` в окне кузнеца.
- Кнопка возврата из рецепта/улучшения теперь использует `guild:blacksmith:menu`.
- Ошибка Discord API 50035 `COMPONENT_CUSTOM_ID_DUPLICATED` устранена.
- Содержимое v18.3.0 сохранено: лечебница, повар, усиленные миньоны и случайный призыв 1–3 миньонов.

## Важно при ошибке `database or disk is full`
Это не ошибка компонентов Discord. На хостинге закончилось свободное место. Перед запуском удалить старые архивы/логи и лишние локальные резервные копии, оставив актуальные базы данных.
