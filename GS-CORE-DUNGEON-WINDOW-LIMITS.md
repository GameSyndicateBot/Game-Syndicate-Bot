# Group Dungeon window limits

- Maximum party size: 5 players.
- Every player can start one dungeon in the daytime window and one dungeon in the evening window.
- The limit is recorded when a raid successfully starts, not when a player merely joins a forming group.
- Every guild receives one shared dungeon and one shared difficulty for the entire Moscow-time window.
- Multiple independent groups may run the same spawned dungeon during that window.
- Recreating a group no longer rerolls dungeon difficulty.
