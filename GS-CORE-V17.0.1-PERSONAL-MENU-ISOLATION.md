# Game Syndicate V17.0.1 — Personal Menu Isolation Fix

## Исправлено

- Нажатие кнопки «Инвентарь» на общей панели Гильдии больше не заменяет публичное сообщение личным меню игрока.
- Каждый игрок получает собственное ephemeral-меню, видимое только ему.
- Переходы внутри уже открытого личного меню продолжают обновлять только это меню.
- Исключено отображение чужого инвентаря из-за общего публичного сообщения.

## Причина

Функция `showInventory()` использовала `interaction.update()` для любого нажатия кнопки.
Из-за этого общая панель Гильдии превращалась в инвентарь последнего нажавшего игрока и становилась видна всем.

Теперь `interaction.update()` используется только для уже существующего ephemeral-сообщения.
При нажатии на публичный Guild Hub бот отвечает через личный ephemeral-ответ.
