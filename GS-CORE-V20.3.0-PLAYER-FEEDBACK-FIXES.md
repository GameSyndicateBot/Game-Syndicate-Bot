# Game Syndicate V20.3.0 — Player Feedback Fixes

- Торговец: покупка материалов теперь поддерживает ввод количества одной операцией.
- Жрец / World Boss: вторичные MVP-награды больше не могут несколько раз выдать паки одному и тому же игроку; общий MVP исключён из вторичных категорий.
- Интеллект: максимальная мана магических классов теперь действительно увеличивается на +2 за каждую единицу итогового интеллекта экипировки; реген и восстановление учитывают новый максимум.
- Алхимическая бомба доступна из боевого рюкзака во время World Boss как дополнительное расходное действие.
- Экспедиции больше не показывают материалы (например железную руду) как «Экипировку».
- Травник перерабатывает 2 Лесные травы -> 1 Экстракт трав; Пряные травы остаются ингредиентом еды.
- Добавлены предметы в пустовавшие категории: пояс, штаны, щит/левая рука; добавлено больше дальнего оружия на ловкость и интеллект и Походный набор.
- Новые предметы включены в таблицы добычи экспедиций и поддерживаются улучшением экипировки.
- Публичное сообщение автоматического распределения по подземельям удаляется через 1 час.
- Сохранены существующие V20.2 исправления классовых комплектов, рынка, обмена, подарков и расчёта шансов подземелий.
