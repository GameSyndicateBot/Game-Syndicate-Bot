# Game Syndicate V17.0.4 — Expedition Hub Recovery

- Новый Expedition Hub теперь создаётся до удаления старого.
- При ошибке отправки канал больше не остаётся пустым.
- Если не загрузилась картинка, бот создаёт рабочий текстовый хаб с кнопками.
- Автовосстановление умеет создать новый хаб, даже если чтение истории сообщений временно недоступно.
- `/control` показывает реальную ошибку Discord/API вместо универсальной надписи о правах.
- Для очистки старых хабов отдельно учитывается право «Читать историю сообщений».
