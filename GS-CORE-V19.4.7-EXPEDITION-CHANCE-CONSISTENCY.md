# GS CORE V19.4.7 — Expedition Chance Consistency

- Экран выбора тактики и фактический запуск теперь используют одну функцию расчёта.
- Для предпросмотра используется именно ежедневная версия локации с погодой и темой дня, а не статический шаблон.
- Учитываются те же активные алхимические, мировые и экипировочные бонусы.
- Рассчитанный процент сохраняется при старте и без повторного пересчёта используется при результате экспедиции.
- Сообщение о старте отображает только сохранённое точное значение.
